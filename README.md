# Clickable

An app that displays a wide array of high-quality images from **Unsplash**, a popular platform known for free, high-resolution photos. Clickable allows users to search for images, browse curated photo collections, and save or download images for personal use.

## Features

- **Search for Images**: Easily search for high-quality photos using keywords.
- **Curated Collections**: Explore curated collections of photos across various categories.
- **Save and Download**: Save your favorite images or download them for offline use.

## Requirements

- iOS 14.0+ (or whichever version you are supporting)
- Internet connection (for fetching images from Unsplash)

## Setup

1. Clone the repository:
    ```bash
    git clone https://github.com/alexdiv12/Clickable.git
    ```

2. Install dependencies (if applicable, for example using CocoaPods or Swift Package Manager):
    ```bash
    pod install
    ```

3. Open the project in Xcode:
    ```bash
    open Clickable.xcworkspace
    ```

4. Run the app on a simulator or physical device.

## API Integration

The app integrates with the [Unsplash API](https://unsplash.com/documentation) to fetch high-quality images. Ensure you have an Unsplash API key to access their photo library.
